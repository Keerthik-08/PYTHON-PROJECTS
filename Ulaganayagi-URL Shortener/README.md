# URL Shortener

A simple URL shortener using **only built-in Node.js** — no npm install required.

## Files
```
url-shortener/
├── server.js       ← Backend (Node.js only, no libraries)
├── index.html      ← Frontend UI
├── .vscode/
│   └── launch.json ← VS Code run config
└── README.md
```

## How to Run

### Option 1 — VS Code (easiest)
1. Open this folder in VS Code
2. Press **F5**
3. Open http://localhost:3000 in your browser

### Option 2 — Terminal
```bash
node server.js
```
Then open http://localhost:3000

## Requirements
- [Node.js](https://nodejs.org) installed (that's it!)
- No `npm install` needed
