
# Modern E-Commerce Web Application

## Features
- Responsive E-Commerce UI
- Product Listings
- Shopping Cart
- Login & Signup
- Admin Dashboard
- Product Filtering & Search
- Dark/Light Mode
- SQLite Database
- Animated Premium UI

## Run Project

### Install Dependencies
pip install -r requirements.txt

### Start Application
streamlit run app.py

## Technologies Used
- Python
- Streamlit
- SQLite
- Pandas
